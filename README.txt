# Котик — проект Android Studio

Приложение повторяет структуру практической работы: четыре кнопки времени суток сверху, четыре сцены, уведомление при смене сцены, всплывающие сообщения для объектов утренней сцены, монохромные прозрачные иконки уведомлений и собственная иконка приложения.

## Открытие
1. Распакуйте архив.
2. В Android Studio выберите File → Open.
3. Откройте папку `Kotik_AndroidStudio` (в ней лежат `settings.gradle.kts`, `build.gradle.kts` и папка `app`).
4. Дождитесь синхронизации Gradle, установите предложенные SDK-компоненты.
5. Запустите на эмуляторе/телефоне кнопкой Run.

## Поведение
- Утро: изображение котика с кормом; уведомление «Покорми котика…».
- День: котик играет; уведомление «Поиграй с котиком…».
- Вечер: котика моют; уведомление о купании.
- Ночь: котик отдыхает; уведомление погладить перед сном.
- В утренней сцене нажмите на котика или миску, чтобы увидеть Toast-сообщение.
- На Android 13+ нужно разрешить приложению отправлять уведомления.

Иллюстрации в `app/src/main/res/drawable`, разметка в `res/layout/activity_main.xml`, обработчики и уведомления в `MainActivity.java`.

## SDK 35
Проект собирается с compileSdk = 35 и targetSdk = 35 (Android 15).
В SDK Manager должна быть установлена платформа «Android 15.0 (API 35)».
Версии библиотек в gradle/libs.versions.toml подобраны под compileSdk 35
(appcompat 1.7.0, material 1.12.0, activity 1.9.3, constraintlayout 2.2.1).
